# แปลข้อความ

การแปล LLM ทันทีด้วยการตรวจจับอัตโนมัติ, สลับภาษา, เอาต์พุตแบบ
สตรีมมิ่ง และการเล่น TTS ดีที่สุดสำหรับข้อความสั้นๆ, การใช้งาน
แบบแชท และการทดสอบการตั้งค่า LLM ของคุณ

## ทีละขั้นตอน

1. คลิก **แปลข้อความ** ในแถบด้านข้าง
2. พิมพ์หรือวางข้อความต้นทางในแผงด้านซ้าย
3. ภาษา **ต้นทาง** ตรวจจับอัตโนมัติขณะพิมพ์ (ขับเคลื่อนโดย
   `langdetect`)
4. เลือกภาษา **เป้าหมาย** จาก dropdown ด้านขวา
5. คลิก **แปล** (หรือกด `Ctrl+Enter`)
6. การแปลสตรีมเข้าสู่แผงด้านขวาทีละ token

## คุณจะได้รับ

- **เอาต์พุตแบบสตรีมมิ่ง** — การแปลปรากฏขณะที่ LLM สร้าง ไม่ต้อง
  รอการตอบสนองทั้งหมด
- **ตรวจจับต้นทางอัตโนมัติ** — ตัวเลือกต้นทางอัปเดตแบบเรียลไทม์
  คลิกเพื่อแทนที่
- **โหมดแก้ไข** — คลิกแผงด้านขวาเพื่อแก้ไขการแปลด้วยตนเอง กด
  `Escape` เพื่อยกเลิกการแปลที่กำลังทำงาน; กดอีกครั้งเพื่อออกจาก
  โหมดแก้ไข
- **ใช้ประวัติซ้ำ** — ทุกการแปลถูกบันทึก คลิกรายการในแผง Text
  Translation History ด้านล่างเพื่อโหลดทั้งสองแผงใหม่; การแก้ไข
  อัปเดตรายการเดิมแทนที่จะสร้างซ้ำ
- **การเล่น TTS** — คลิกปุ่ม **ฟัง** ข้างแผงใดก็ตามเพื่อฟังอ่าน
  ออกมา เคารพการเลือก **Settings → Voice → TTS method** ของคุณ —
  Edge TTS (ค่าเริ่มต้น), ElevenLabs, Google Cloud TTS, Gemini
  TTS, หรือ **Piper TTS** (ออฟไลน์เต็มรูปแบบ) เมื่อเลือก Piper
  ปุ่มฟังจะรัน pre-flight เดียวกับหน้า Voice: เสียงต่อภาษาที่หาย
  ไปจะแสดง modal dialog พร้อมปุ่ม **Open Settings** เพื่อให้คุณ
  ดาวน์โหลดได้ การเรียก cache hit ข้าม pre-flight ทั้งหมด
- **ตัวเลือกโมเดลต่อฟีเจอร์** — เมื่อมี LLM กำหนดค่ามากกว่าหนึ่ง
  dropdown ให้คุณเลือกโมเดล Flash ที่เร็วสำหรับความเร็วหรือ Pro
  ที่หนักกว่าสำหรับคุณภาพ เฉพาะหน้านี้

## ทางลัด

| ทางลัด | การกระทำ |
|---|---|
| `Ctrl+Enter` | แปล |
| `Ctrl+L` | สลับต้นทาง ↔ เป้าหมาย |
| `Escape` | ยกเลิกการแปลที่กำลังทำงาน หรือออกจากโหมดแก้ไข |
| `Ctrl+F` | โฟกัสค้นหาประวัติ |

## เคล็ดลับ

!!! tip "ภาษา RTL"
    การแปลเป็น **อาหรับ**, **ฮีบรู** หรือ **เปอร์เซีย** จะเรนเดอร์
    จากขวาไปซ้ายโดยอัตโนมัติในแผงเอาต์พุต การจัดการ RTL เดียวกัน
    นี้ส่งต่อไปยังเอาต์พุตไฟล์ในทุกรูปแบบในหน้า
    [แปลเอกสาร](translate-document.md) (PDF, DOCX, PPTX, XLSX,
    ODF, RTF, HTML, EPUB, ASS/SSA) และเปอร์เซียได้รับเสียง
    `fa-IR` แบบ native สำหรับการเล่น Edge TTS

!!! tip "Cache ปุ่มฟัง"
    ครั้งแรกที่คุณกดฟังบนคู่ (ข้อความ, ภาษา) ใดๆ เสียงจะถูก
    สังเคราะห์และแคชบนดิสก์ การเล่นถัดไปจะทันที Cache ถูกล้างเมื่อ
    เริ่มแอป ดังนั้นแต่ละ session เริ่มใหม่

!!! tip "คีย์ไปที่ไหน"
    หน้าแปลข้อความอ่านรายการ keychain เดียวกับส่วนที่เหลือของแอป
    — ดู[ผู้ให้บริการ LLM](../setup/llm-providers.md)
