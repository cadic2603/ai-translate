# 翻译文本

具有自动检测、语言交换、流式输出和 TTS 播放的即时 LLM 翻译。最适合
短片段、聊天式使用和测试 LLM 设置。

## 步骤

1. 点击侧边栏中的**翻译文本**。
2. 在左侧面板中键入或粘贴源文本。
3. 键入时**源**语言自动检测(由 `langdetect` 支持)。
4. 从右侧下拉菜单选择**目标**语言。
5. 点击**翻译**(或按 `Ctrl+Enter`)。
6. 翻译以流式方式逐 token 进入右侧面板。

## 您获得什么

- **流式输出**——翻译随着 LLM 生成而出现,无需等待整个响应。
- **自动检测源**——源选择器实时更新。点击以覆盖。
- **编辑模式**——点击右侧面板手动编辑翻译。按 `Esc` 取消正在进行的翻译;
  再次按以退出编辑模式。
- **历史重用**——每次翻译都被保存。点击下方文本翻译历史面板中的条目
  重新加载两个面板;编辑更新原始条目而不是创建副本。
- **TTS 播放**——点击任一面板旁边的**收听**以听到朗读。遵循您在
  **设置 → 语音 → TTS 方法**中的选择——Edge TTS(默认)、ElevenLabs、
  Google Cloud TTS、Gemini TTS 或 **Piper TTS**(完全离线)。选择 Piper 时,
  收听按钮运行与语音页面相同的 pre-flight:缺少的每语言语音会显示一个
  带**打开设置**按钮的模态对话框以下载。缓存命中完全跳过 pre-flight。
- **每功能模型选择器**——配置多个 LLM 时,下拉菜单允许您选择快速 Flash
  模型以提高速度或更重的 Pro 模型以提高质量,仅适用于此页面。

## 快捷键

| 快捷键 | 操作 |
|---|---|
| `Ctrl+Enter` | 翻译 |
| `Ctrl+L` | 交换源 ↔ 目标 |
| `Esc` | 取消进行中的翻译,或退出编辑模式 |
| `Ctrl+F` | 聚焦历史搜索 |

## 技巧

!!! tip "RTL 语言"
    翻译为**阿拉伯语**、**希伯来语**或**波斯语**会自动在输出面板中从右
    向左渲染。相同的 RTL 处理传播到[翻译文档](translate-document.md)
    页面上每种格式的文件输出(PDF、DOCX、PPTX、XLSX、ODF、RTF、HTML、
    EPUB、ASS/SSA),波斯语获得用于 Edge TTS 播放的原生 `fa-IR` 语音。

!!! tip "收听按钮缓存"
    您第一次点击给定(文本、语言)对的收听时,音频被合成并缓存到磁盘。
    后续播放是即时的。缓存在应用启动时被清空,因此每个会话都从头开始。

!!! tip "密钥存放位置"
    翻译文本页面读取与应用其余部分相同的钥匙串条目——参见
    [LLM 提供商](../setup/llm-providers.md)。
