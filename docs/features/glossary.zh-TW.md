# 術語表

將特定術語鎖定到每個翻譯作業中的特定翻譯。對品牌名稱、產品術語、技術術語
或您想保持一致的角色名稱很有用。

## 工作原理

術語表是按**集合**分組的(源術語、目标術語)對的清單。当您開啟一個集合時,
應用中的每個 LLM 調用都會將相關條目注入到 prompt 中——因此 LLM 在翻譯前
看到"對'OpenAI'使用'OpenAI',而不是'開放AI'"。

可以同時激活多個集合。只有源或目标出現在批次文本中的條目才會被添加到
prompt 中(每次調用壓縮),因此套件含 5,000 條記錄的術語表在 token 上仍然便宜。

## 步驟

1. 點擊側欄中的**術語表**。
2. 點擊**新集合**(`Ctrl+N`)並給它命名(例如"Acme 專案")。
3. 左側選擇集合后,右側面板顯示其條目。
4. 點擊**添加**以創建新條目。填寫:
    - **源**——原始術語
    - **目标**——要強制的翻譯
    - 選用的註解 / 筆記
5. 對每個術語重復。
6. 勾選集合名稱上的**激活**復選框以啟用。

## 激活 / 停用集合

每個集合名稱旁邊的**激活**復選框控制其條目是否注入到 LLM prompt 中。
您可以將 50 個非激活集合保留在儲存中,僅為目前專案激活所需的 2 個。

## 匯入 / 匯出 (CSV)

- **匯出**——選擇一個集合,點擊**匯出** → 另存為 `.csv`。兩列:`source`、
  `target`(UTF-8,逗號分隔,RFC 4180 引用)。
- **匯入**——點擊**匯入** → 選擇 `.csv` → 選擇目标集合(現有或新建)。
  在重復的源上,您將獲得取代-或-跳過提示。

CSV 格式可以 round-trip,因此匯出 → 在 Excel 中編輯 → 匯入是安全的。

## 搜尋和過濾

`Ctrl+F` 聚焦搜尋欄。鍵入任何子字串,條目(和集合清單)將過濾到匹配项;
匹配的子字串被高亮。清除搜尋還原完整清單。

搜尋是**不區分重音和不區分大小寫**的——`cafe` 找到 `café`,反之亦然。

## 就地編輯

點擊任何單元格進行編輯。按 `Tab` 移到下一個單元格。按 `Esc` 還原。
当您單擊行外時觸發自動儲存。空的源或目标會還原行,而不是儲存無效條目。

## 刪除

- **刪除單個條目**——選擇它,按 `Del`。您將看到確認對話方塊。
- **刪除整個集合**——選擇集合,按 `Del`。對話方塊顯示級聯條目計數,
  以便您知道要清除什麼。

## 快速鍵

| 快速鍵 | 操作 |
|---|---|
| `Ctrl+N` | 新集合 |
| `Ctrl+F` | 聚焦搜尋 |
| `Del` | 刪除選定條目 / 集合 |

## 技巧

!!! tip "按集合范圍"
    集合是*邏輯*分組。按專案、按客戶、按領域(醫療/法律/游戲)分組——
    任何有意義的方式。僅激活與目前工作相關的集合。

!!! tip "術語表不會覆蓋翻譯"
    指示 LLM 使用術語表條目,但它仍然是一個提示——極度不自然的強制翻譯
    仍可能出現。使用簡單的`術語 → 翻譯`對而不是完整的句子。
