# Извлечение текста

Вытащите текст из изображений — чеки, скриншоты, сфотографированные
документы, отсканированные страницы, всё что угодно. Вывод в `.txt`
(обычный) или `.docx` (форматированные параграфы).

Эта страница **не переводит** — только извлекает. Передайте вывод
в «Перевод документа», если вам также нужен перевод.

## Два метода извлечения

| Метод | Лучше всего для |
|---|---|
| **OCR** | Большие объёмы / batch / чувствительно к стоимости (бесплатно или почти бесплатно за изображение) |
| **Vision LLM** | Сохранение вёрстки, смешанные скрипты, изображения низкого качества, рукопись |

Выберите по умолчанию в **Настройки → Извлечение текста → Метод извлечения**.

## OCR-движки (OCR-метод)

| Движок | Стоимость | Офлайн | Языки | Заметки |
|---|---|---|---|---|
| **Tesseract** | Бесплатно | Да | 100+ | По умолчанию. Нужна системная установка. |
| **EasyOCR** | Бесплатно | Да (после загрузки модели) | 80+ | Лучше всего для не-латинских скриптов. ~1 ГБ моделей. |
| **Google Cloud Vision** | Платно (1 000 бесплатно / месяц) | Нет | 60+ | Высочайшая точность. |

Настройте в **Настройки → OCR**.

## Пошагово

1. Нажмите **Извлечение текста** в боковой панели.
2. Сбросьте один или несколько файлов изображений (`.png`, `.jpg`,
   `.jpeg`, `.bmp`, `.webp`, `.tiff`, `.tif`).
3. Выберите **Исходный язык** (помогает OCR выбрать правильную модель).
4. Выберите **Формат вывода** — `.txt` или `.docx`.
5. Нажмите **Извлечь** (или `Ctrl+Enter`).
6. **Откройте** строку по завершении.

## Когда что использовать

- **Чек / счёт, насыщенный текстом** → Tesseract быстрый и точный.
- **Сфотографированные рукописные заметки** → vision LLM выигрывает с большим отрывом.
- **Манга / комикс** → EasyOCR (хорошо обрабатывает вертикальный CJK-текст).
- **Форма с множеством мелких полей** → Google Cloud Vision обычно
  лучше сохраняет границы полей, чем другие.

## Советы

!!! tip "OCR или LLM, не оба"
    Страница выбирает один метод и запускает. Чтобы сравнить выводы,
    запустите одно и то же изображение дважды с разными методами.

!!! tip "Диалог «Требуется настройка»"
    Если вы выберете OCR, но не настроен ни один OCR-движок (или LLM,
    но не настроен LLM-ключ), страница покажет один диалог «Требуется
    настройка», который ведёт прямо к соответствующей вкладке
    Настройки.

## Горячие клавиши

|---|---|

| `Ctrl+O` | Обзор |
