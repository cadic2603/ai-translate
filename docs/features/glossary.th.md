# คำศัพท์

ล็อกคำศัพท์เฉพาะกับการแปลเฉพาะในทุกงานแปล มีประโยชน์สำหรับชื่อแบรนด์
คำศัพท์ผลิตภัณฑ์ ศัพท์เทคนิค หรือชื่อตัวละครที่คุณต้องการให้สอดคล้อง
กัน

## ทำงานอย่างไร

คำศัพท์เป็นรายการของคู่ (คำต้นทาง, คำเป้าหมาย) ที่จัดกลุ่มเป็น
**ชุด** เมื่อคุณเปิดชุด ทุกการเรียก LLM ในแอปจะได้รับรายการที่
เกี่ยวข้องที่ฉีดเข้าไปใน prompt — ดังนั้น LLM เห็น "ใช้ 'OpenAI'
แทน 'OpenAI' ไม่ใช่ '开放AI'" ก่อนที่จะแปล

หลายชุดสามารถใช้งานพร้อมกันได้ เฉพาะรายการที่มีต้นทางหรือเป้าหมาย
ปรากฏในข้อความ batch จะถูกเพิ่มเข้าไปใน prompt (การบีบอัดต่อการ
เรียก) ดังนั้นคำศัพท์ 5,000 รายการยังคงราคาไม่แพงในเรื่อง tokens

## ทีละขั้นตอน

1. คลิก **คำศัพท์** ในแถบด้านข้าง
2. คลิก **New Set** (`Ctrl+N`) และตั้งชื่อ (เช่น "Project Acme")
3. เมื่อเลือกชุดทางซ้าย แผงด้านขวาจะแสดงรายการของชุดนั้น
4. คลิก **Add** เพื่อสร้างรายการใหม่ กรอก:
    - **Source** — คำต้นฉบับ
    - **Target** — การแปลที่จะบังคับใช้
    - ตัวเลือกความคิดเห็น / โน้ต
5. ทำซ้ำสำหรับแต่ละคำศัพท์
6. ทำเครื่องหมายในกล่อง **Active** บนชื่อชุดเพื่อเปิดใช้งาน
   สำหรับการแปล

## เปิด / ปิดใช้งานชุด

กล่องเลือก **Active** ข้างชื่อชุดแต่ละชุดควบคุมว่ารายการของมันจะถูก
ฉีดเข้าไปใน prompts ของ LLM หรือไม่ คุณสามารถปล่อยชุดที่ไม่ใช้งาน
50 ชุดในที่เก็บข้อมูลและเปิดเฉพาะ 2 ชุดที่คุณต้องการสำหรับโครงการ
ปัจจุบัน

## นำเข้า / ส่งออก (CSV)

- **Export** — เลือกชุด คลิก **Export** → บันทึกเป็น `.csv`
  สองคอลัมน์: `source`, `target` (UTF-8, คั่นด้วยเครื่องหมายจุลภาค,
  RFC 4180-quoted)
- **Import** — คลิก **Import** → เลือก `.csv` → เลือกชุดปลายทาง
  (ที่มีอยู่หรือใหม่) ในต้นทางที่ซ้ำ คุณจะได้รับ prompt ให้
  แทนที่หรือข้าม

รูปแบบ CSV round-trip ดังนั้น Export → แก้ไขใน Excel → Import
จึงปลอดภัย

## ค้นหาและกรอง

`Ctrl+F` โฟกัสกล่องค้นหา พิมพ์ substring ใดๆ และรายการ (และรายการ
ชุด) จะกรองเป็นการจับคู่; substring ที่จับคู่จะถูกเน้น การล้างการ
ค้นหาคืนรายการเต็มรูปแบบ

การค้นหา **ไม่สนใจวรรณยุกต์และไม่คำนึงถึงตัวพิมพ์ใหญ่/เล็ก** —
`cafe` พบ `café` และในทางกลับกัน

## แก้ไขในที่

คลิกเซลล์ใดๆ เพื่อแก้ไข กด `Tab` เพื่อย้ายไปยังเซลล์ถัดไป กด `Esc`
เพื่อย้อนกลับ การบันทึกอัตโนมัติเรียกใช้เมื่อคุณคลิกออกจากแถว
ต้นทางหรือเป้าหมายว่างจะย้อนแถวแทนที่จะบันทึกรายการที่ไม่ถูกต้อง

## ลบ

- **ลบรายการเดียว** — เลือก กด `Delete` คุณจะเห็น dialog ยืนยัน
- **ลบทั้งชุด** — เลือกชุด กด `Delete` Dialog แสดงจำนวนรายการที่
  เป็น cascade เพื่อให้คุณรู้ว่ากำลังลบอะไร

## ทางลัด

| ทางลัด | การกระทำ |
|---|---|
| `Ctrl+N` | ชุดใหม่ |
| `Ctrl+F` | โฟกัสค้นหา |
| `Delete` | ลบรายการ / ชุดที่เลือก |

## เคล็ดลับ

!!! tip "ขอบเขตต่อชุด"
    ชุดเป็นการจัดกลุ่ม *เชิงตรรกะ* จัดกลุ่มตามโครงการ ตามลูกค้า
    ตามโดเมน (การแพทย์ / กฎหมาย / เกม) — อะไรก็ตามที่สมเหตุสมผล
    เปิดใช้งานเฉพาะชุดที่เกี่ยวข้องกับงานปัจจุบัน

!!! tip "คำศัพท์ไม่แทนที่การแปล"
    LLM ได้รับคำสั่งให้ใช้รายการคำศัพท์ แต่ยังคงเป็นคำใบ้ — การแปล
    บังคับที่อึดอัดมากยังสามารถปรากฏได้ ใช้คู่
    `term → translation` ที่เรียบง่ายมากกว่าประโยคเต็ม
