# 텍스트 번역

자동 감지, 언어 교체, 스트리밍 출력, TTS 재생을 갖춘 즉시 LLM 번역.
짧은 스니펫, 채팅 스타일 사용, LLM 설정 테스트에 가장 적합.

## 단계

1. 사이드바에서 **텍스트 번역** 클릭.
2. 왼쪽 패널에 소스 텍스트를 입력하거나 붙여넣기.
3. **소스** 언어는 입력하는 동안 자동 감지됩니다 (`langdetect` 사용).
4. 오른쪽 드롭다운에서 **대상** 언어 선택.
5. **번역** 클릭 (또는 `Ctrl+Enter` 누르기).
6. 번역이 토큰별로 오른쪽 패널에 스트리밍됩니다.

## 얻는 것

- **스트리밍 출력** — 번역이 LLM이 생성함에 따라 나타나며, 전체
  응답을 기다리지 않습니다.
- **자동 소스 감지** — 소스 선택기가 실시간으로 업데이트됩니다.
  재정의하려면 클릭하세요.
- **편집 모드** — 오른쪽 패널을 클릭하여 번역을 수동으로 편집합니다.
  진행 중인 번역을 취소하려면 `Esc`를 누르세요; 편집 모드를 종료
  하려면 다시 누르세요.
- **히스토리 재사용** — 모든 번역이 저장됩니다. 아래의 텍스트 번역
  히스토리 패널의 항목을 클릭하여 두 패널을 다시 로드하세요; 편집은
  복사본을 만드는 대신 원본 항목을 업데이트합니다.
- **TTS 재생** — 어느 패널 옆의 **듣기**를 클릭하여 큰 소리로 읽어
  듣습니다. **설정 → 음성 → TTS 방법** 선택을 따릅니다 —
  Edge TTS (기본), ElevenLabs, Google Cloud TTS, Gemini TTS 또는
  **Piper TTS** (완전 오프라인). Piper 선택 시, 듣기 버튼은 음성
  페이지와 동일한 pre-flight를 실행합니다: 누락된 언어별 음성은
  다운로드를 위한 **설정 열기** 버튼이 있는 모달 대화 상자를 표시
  합니다. 캐시 히트는 pre-flight를 완전히 건너뜁니다.
- **기능별 모델 선택기** — 여러 LLM이 구성된 경우, 드롭다운으로
  속도를 위한 빠른 Flash 모델 또는 품질을 위한 더 무거운 Pro 모델을
  선택할 수 있습니다, 이 페이지만.

## 단축키

| 단축키 | 동작 |
|---|---|
| `Ctrl+Enter` | 번역 |
| `Ctrl+L` | 소스 ↔ 대상 교체 |
| `Esc` | 진행 중인 번역 취소, 또는 편집 모드 종료 |
| `Ctrl+F` | 히스토리 검색에 포커스 |

## 팁

!!! tip "RTL 언어"
    **아랍어**, **히브리어** 또는 **페르시아어**로의 번역은 출력
    패널에서 자동으로 오른쪽에서 왼쪽으로 렌더링됩니다. 동일한 RTL
    처리가 [문서 번역](translate-document.md) 페이지의 모든 형식
    파일 출력으로 이어집니다 (PDF, DOCX, PPTX, XLSX, ODF, RTF,
    HTML, EPUB, ASS/SSA), 페르시아어는 Edge TTS 재생을 위한 네이티브
    `fa-IR` 음성을 받습니다.

!!! tip "듣기 버튼 캐시"
    특정 (텍스트, 언어) 쌍에 대해 처음 듣기를 누르면 오디오가 합성
    되어 디스크에 캐시됩니다. 이후 재생은 즉시입니다. 캐시는 앱 시작
    시 지워지므로 각 세션이 새로 시작됩니다.

!!! tip "키가 저장되는 곳"
    텍스트 번역 페이지는 앱의 나머지 부분과 동일한 키체인 항목을
    읽습니다 — [LLM 제공자](../setup/llm-providers.md) 참조.
