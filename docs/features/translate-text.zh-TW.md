# 翻譯文本

具有自動檢測、語言交換、流式輸出和 TTS 播放的即時 LLM 翻譯。最适合
短片段、聊天式使用和測試 LLM 設定。

## 步驟

1. 點擊側欄中的**翻譯文本**。
2. 在左側面板中鍵入或貼上源文本。
3. 鍵入時**源**語言自動檢測(由 `langdetect` 支援)。
4. 從右側下拉選單選擇**目标**語言。
5. 點擊**翻譯**(或按 `Ctrl+Enter`)。
6. 翻譯以流式方式逐 token 進入右側面板。

## 您獲得什麼

- **流式輸出**——翻譯隨著 LLM 生成而出現,無需等待整個回應。
- **自動檢測源**——源選擇器即時更新。點擊以覆蓋。
- **編輯模式**——點擊右側面板手動編輯翻譯。按 `Esc` 取消正在進行的翻譯;
  再次按以結束編輯模式。
- **歷史重用**——每次翻譯都被儲存。點擊下方文本翻譯歷史面板中的條目
  重新載入兩個面板;編輯更新原始條目而不是創建副本。
- **TTS 播放**——點擊任一面板旁邊的**收聽**以聽到朗讀。遵循您在
  **設定 → 語音 → TTS 方法**中的選擇——Edge TTS(預設)、ElevenLabs、
  Google Cloud TTS、Gemini TTS 或 **Piper TTS**(完全離線)。選擇 Piper 時,
  收聽按鈕執行與語音頁面相同的 pre-flight:缺少的每語言語音會顯示一個
  帶**開啟設定**按鈕的模態對話方塊以下載。快取命中完全跳過 pre-flight。
- **每功能模型選擇器**——設定多個 LLM 時,下拉選單允許您選擇快速 Flash
  模型以提高速度或更重的 Pro 模型以提高品質,僅适用於此頁面。

## 快速鍵

| 快速鍵 | 操作 |
|---|---|
| `Ctrl+Enter` | 翻譯 |
| `Ctrl+L` | 交換源 ↔ 目标 |
| `Esc` | 取消進行中的翻譯,或結束編輯模式 |
| `Ctrl+F` | 聚焦歷史搜尋 |

## 技巧

!!! tip "RTL 語言"
    翻譯為**阿拉伯語**、**希伯來語**或**波斯語**會自動在輸出面板中從右
    向左渲染。相同的 RTL 處理傳播到[翻譯文件](translate-document.md)
    頁面上每種格式的檔案輸出(PDF、DOCX、PPTX、XLSX、ODF、RTF、HTML、
    EPUB、ASS/SSA),波斯語獲得用於 Edge TTS 播放的原生 `fa-IR` 語音。

!!! tip "收聽按鈕快取"
    您第一次點擊給定(文本、語言)對的收聽時,音訊被合成並快取到磁盤。
    后續播放是即時的。快取在應用啟動時被清空,因此每個會話都從頭開始。

!!! tip "密鑰存放位置"
    翻譯文本頁面讀取與應用其余部分相同的鑰匙串條目——參見
    [LLM 提供商](../setup/llm-providers.md)。
