# 术语表

将特定术语锁定到每个翻译作业中的特定翻译。对品牌名称、产品术语、技术术语
或您想保持一致的角色名称很有用。

## 工作原理

术语表是按**集合**分组的(源术语、目标术语)对的列表。当您打开一个集合时,
应用中的每个 LLM 调用都会将相关条目注入到 prompt 中——因此 LLM 在翻译前
看到"对'OpenAI'使用'OpenAI',而不是'开放AI'"。

可以同时激活多个集合。只有源或目标出现在批次文本中的条目才会被添加到
prompt 中(每次调用压缩),因此包含 5,000 条记录的术语表在 token 上仍然便宜。

## 步骤

1. 点击侧边栏中的**术语表**。
2. 点击**新集合**(`Ctrl+N`)并给它命名(例如"Acme 项目")。
3. 左侧选择集合后,右侧面板显示其条目。
4. 点击**添加**以创建新条目。填写:
    - **源**——原始术语
    - **目标**——要强制的翻译
    - 可选的注释 / 笔记
5. 对每个术语重复。
6. 勾选集合名称上的**激活**复选框以启用。

## 激活 / 停用集合

每个集合名称旁边的**激活**复选框控制其条目是否注入到 LLM prompt 中。
您可以将 50 个非激活集合保留在存储中,仅为当前项目激活所需的 2 个。

## 导入 / 导出 (CSV)

- **导出**——选择一个集合,点击**导出** → 另存为 `.csv`。两列:`source`、
  `target`(UTF-8,逗号分隔,RFC 4180 引用)。
- **导入**——点击**导入** → 选择 `.csv` → 选择目标集合(现有或新建)。
  在重复的源上,您将获得替换-或-跳过提示。

CSV 格式可以 round-trip,因此导出 → 在 Excel 中编辑 → 导入是安全的。

## 搜索和过滤

`Ctrl+F` 聚焦搜索栏。键入任何子字符串,条目(和集合列表)将过滤到匹配项;
匹配的子字符串被高亮。清除搜索还原完整列表。

搜索是**不区分重音和不区分大小写**的——`cafe` 找到 `café`,反之亦然。

## 就地编辑

点击任何单元格进行编辑。按 `Tab` 移到下一个单元格。按 `Esc` 还原。
当您单击行外时触发自动保存。空的源或目标会还原行,而不是保存无效条目。

## 删除

- **删除单个条目**——选择它,按 `Del`。您将看到确认对话框。
- **删除整个集合**——选择集合,按 `Del`。对话框显示级联条目计数,
  以便您知道要清除什么。

## 快捷键

| 快捷键 | 操作 |
|---|---|
| `Ctrl+N` | 新集合 |
| `Ctrl+F` | 聚焦搜索 |
| `Del` | 删除选定条目 / 集合 |

## 技巧

!!! tip "按集合范围"
    集合是*逻辑*分组。按项目、按客户、按领域(医疗/法律/游戏)分组——
    任何有意义的方式。仅激活与当前工作相关的集合。

!!! tip "术语表不会覆盖翻译"
    指示 LLM 使用术语表条目,但它仍然是一个提示——极度不自然的强制翻译
    仍可能出现。使用简单的`术语 → 翻译`对而不是完整的句子。
