# Перевод текста

Мгновенный LLM-перевод с авто-определением, обменом языков,
потоковым выводом и воспроизведением TTS. Лучше всего для коротких
фрагментов, использования в стиле чата и тестирования вашей настройки LLM.

## Пошагово

1. Нажмите **Перевод текста** в боковой панели.
2. Наберите или вставьте исходный текст в левую панель.
3. **Исходный** язык авто-определяется по мере набора (с помощью `langdetect`).
4. Выберите **Целевой** язык из правого dropdown.
5. Нажмите **Перевести** (или `Ctrl+Enter`).
6. Перевод поступает потоком token за token в правую панель.

## Что вы получаете

- **Потоковый вывод** — перевод появляется по мере генерации LLM,
  без ожидания всего ответа.
- **Авто-определение источника** — селектор источника обновляется
  в реальном времени. Кликните, чтобы переопределить.
- **Режим редактирования** — кликните по правой панели, чтобы
  редактировать перевод вручную. Нажмите `Esc`, чтобы отменить
  выполняющийся перевод; нажмите снова, чтобы выйти из режима
  редактирования.
- **Повторное использование истории** — каждый перевод сохраняется.
  Кликните запись в панели «История перевода текста» ниже, чтобы
  перезагрузить обе панели; редактирования обновляют исходную запись
  вместо создания дубля.
- **Воспроизведение TTS** — нажмите **Слушать** рядом с любой
  панелью, чтобы услышать вслух. Уважает ваш выбор в
  **Настройки → Голос → Метод TTS** — Edge TTS (по умолчанию),
  ElevenLabs, Google Cloud TTS, Gemini TTS или **Piper TTS**
  (полностью офлайн). С выбранным Piper кнопка Слушать выполняет
  тот же pre-flight, что и страница Голоса: отсутствующий голос для
  языка показывает modal-диалог с кнопкой **Открыть настройки** для
  загрузки. Cache hits полностью пропускают pre-flight.
- **Селектор модели по функциям** — когда настроено более одного
  LLM, dropdown позволяет выбрать быструю модель Flash для скорости
  или более тяжёлую Pro для качества — только для этой страницы.

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| `Ctrl+Enter` | Перевести |
| `Ctrl+L` | Поменять источник ↔ цель |
| `Esc` | Отменить выполняющийся перевод или выйти из режима редактирования |
| `Ctrl+F` | Фокус на поиск истории |

## Советы

!!! tip "RTL-языки"
    Переводы на **арабский**, **иврит** или **персидский** автоматически
    рендерятся справа налево в выходной панели. Та же RTL-обработка
    переходит в файловый вывод в любом формате на странице
    [Перевод документа](translate-document.md) (PDF, DOCX, PPTX,
    XLSX, ODF, RTF, HTML, EPUB, ASS/SSA), и персидский получает
    нативный голос `fa-IR` для воспроизведения Edge TTS.

!!! tip "Кэш кнопки Слушать"
    При первом нажатии «Слушать» для пары (текст, язык) аудио
    синтезируется и кэшируется на диске. Последующие воспроизведения
    мгновенны. Кэш очищается при запуске приложения, так что каждая
    сессия начинается заново.

!!! tip "Куда идут ключи"
    Страница «Перевод текста» читает те же записи keychain, что и
    остальная часть приложения — см.
    [LLM-провайдеры](../setup/llm-providers.md).
