# ترجمتك الأولى

تشغيل سريع من البداية إلى النهاية — أقل من 5 دقائق بعد الانتهاء من
الإعداد.

!!! abstract "قبل أن تبدأ"
    تحتاج إلى إكمال [التثبيت](installation.md) وتكوين مفتاح API لـ
    LLM. المستوى المجاني من Google Gemini كافٍ للمحاولة الأولى.

## ترجمة مستند Word

1. شغّل تطبيق سطح المكتب:

    ```bash
    uv run python -m src.main
    ```

2. انقر **ترجمة المستند** في الشريط الجانبي الأيسر.

3. اسحب أي ملف `.docx` إلى منطقة الإفلات — أو انقر **استعراض**
   لاختيار واحد.

4. يظهر الملف في قائمة الانتظار. اختر لغة الهدف في الأعلى:

    - المصدر: `Auto-detect` (الافتراضي — عادة صحيح)
    - الهدف: مثل `French` أو `Vietnamese` أو `Japanese` أو
      `Chinese (Simplified)`

5. انقر **ترجمة** (أو اضغط `Ctrl+Enter`).

6. راقب شريط التقدم في جدول السجل أسفل الصفحة. عندما يصل إلى 100%،
   انقر **فتح** على الصف لفتح الملف المترجم — محفوظ بجانب الأصل
   بلاحقة `_translated_<src>_<tgt>`.

## ماذا حدث للتو

- تم استنساخ ملف `.docx` الخاص بك إلى مجلد تخزين لكل مهمة بحيث لا
  يتم لمس الأصل.
- تم استخراج النص، وتجميعه في أجزاء صديقة لـ LLM، وترجمته، ثم إعادة
  حقنه في المستند مع الحفاظ على جميع التنسيقات (الخط الغامق،
  المائل، الخطوط، الألوان، الرؤوس، الحواشي السفلية، الروابط…).
- تمت كتابة إدخال سجل في قاعدة بيانات SQLite حتى تتمكن من إعادة
  فتح أو إعادة تشغيل أو إعادة ترجمة الملف لاحقًا.

## جرّب المكاسب السريعة بعد ذلك

=== "ترجمة نص عادي"

    انتقل إلى **ترجمة النص** في الشريط الجانبي. الصق أي شيء، اختر
    هدفًا، اضغط Enter. إخراج متدفق، تبديل اللغة (`Ctrl+L`)، وضع
    التحرير، تشغيل TTS.

=== "إنشاء ترجمات"

    **إنشاء الترجمة** — أفلِت ملف `.mp4`. ستحصل على ملف `.srt` بلغة
    المصدر. (لترجمة الفيديو _ودبلجته_، استخدم صفحة الدبلجة بدلاً من
    ذلك.)

=== "ترجمة الميكروفون المباشرة"

    **الترجمة الفورية** — اختر الميكروفون أو صوت النظام، اختر هدفًا،
    ابدأ. تعرض نافذة overlay عائمة الترجمات في الوقت الفعلي.
