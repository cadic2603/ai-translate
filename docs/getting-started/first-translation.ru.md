# Ваш первый перевод

Быстрый сквозной прогон — менее 5 минут после завершения настройки.

!!! abstract "Перед началом"
    Вам нужно завершить [установку](installation.md) и настроить
    API-ключ LLM. Бесплатного уровня Google Gemini достаточно для
    первой попытки.

## Перевести документ Word

1. Запустите десктопное приложение:

    ```bash
    uv run python -m src.main
    ```

2. Нажмите **Перевод документа** в левой боковой панели.

3. Перетащите любой файл `.docx` в зону сброса — или нажмите
   **Обзор**, чтобы выбрать.

4. Файл появится в очереди. Выберите целевой язык вверху:

    - Источник: `Автоопределение` (по умолчанию — обычно верно)
    - Цель: например `Французский`, `Вьетнамский`, `Японский`, `Китайский (Упрощённый)`

5. Нажмите **Перевести** (или нажмите `Ctrl+Enter`).

6. Наблюдайте за индикатором прогресса в таблице истории внизу
   страницы. Когда он достигнет 100%, нажмите **Открыть** в строке,
   чтобы открыть переведённый файл — сохранён рядом с оригиналом с
   суффиксом `_translated_<src>_<tgt>`.

## Что только что произошло

- Ваш `.docx` был склонирован в папку хранения для каждой задачи,
  чтобы оригинал не был тронут.
- Текст был извлечён, разбит на чанки, удобные для LLM, переведён,
  затем повторно вставлен в документ со всем сохранённым
  форматированием (жирный, курсив, шрифты, цвета, заголовки, сноски,
  гиперссылки…).
- Запись истории была записана в SQLite БД, чтобы вы могли позже
  переоткрыть, перезапустить или перевести заново файл.

## Попробуйте быстрые победы дальше

=== "Перевод обычного текста"

    Загляните в **Перевод текста** в боковой панели. Вставьте что-либо,
    выберите цель, нажмите Enter. Потоковый вывод, обмен языков
    (`Ctrl+L`), режим редактирования, воспроизведение TTS.

=== "Создать субтитры"

    **Создание субтитров** — бросьте `.mp4`. Получите `.srt` на
    исходном языке. (Чтобы перевести _и_ озвучить видео, используйте
    страницу Дубляж.)

=== "Живой перевод микрофона"

    **Живой перевод** — выберите микрофон или системное аудио,
    выберите цель, Старт. Плавающее окно overlay показывает субтитры
    в реальном времени.
