# 您的第一次翻譯

一次快速的端到端執行——設定完成后不到 5 分鐘。

!!! abstract "開始之前"
    您需要完成[安裝](installation.md)並設定一個 LLM API 密鑰。
    免費的 Google Gemini 層足以進行首次嘗試。

## 翻譯一個 Word 文件

1. 啟動桌面應用程式:

    ```bash
    uv run python -m src.main
    ```

2. 點擊左側欄中的**翻譯文件**。

3. 將任何 `.docx` 檔案拖到放置區——或點擊**瀏覽**選擇一個。

4. 檔案出現在佇列中。在頂部選擇目标語言:

    - 源:`自動檢測`(預設——通常正確)
    - 目标:例如 `法語`、`越南語`、`日語`、`中文(簡體)`

5. 點擊**翻譯**(或按 `Ctrl+Enter`)。

6. 觀察頁面底部歷史表格中的進度列。当達到 100% 時,點擊行上的
   **開啟**以開啟翻譯后的檔案——儲存在原檔案旁邊,帶有
   `_translated_<src>_<tgt>` 后綴。

## 剛才發生了什麼

- 您的 `.docx` 被克隆到每個任務的儲存檔案夾中,使原檔案不被觸動。
- 文本被提取,批處理為 LLM 友好的塊,翻譯,然後重新注入到文件中,
  保留所有格式(粗體、斜體、字型、顏色、标題、腳注、超鏈接…)。
- 歷史記錄條目被寫入 SQLite 資料庫,以便您稍后可以重新開啟、
  重新執行或重新翻譯該檔案。

## 接下來試試快速勝利

=== "翻譯純文本"

    弹到側欄中的**翻譯文本**。貼上任何內容,選擇目标,按 Enter。
    流式輸出、語言交換(`Ctrl+L`)、編輯模式、TTS 播放。

=== "生成字幕"

    **生成字幕**——丟入一個 `.mp4`。您將獲得源語言的 `.srt`。
    (要翻譯_並_配音影片,改用配音頁面。)

=== "即時麥克風翻譯"

    **即時翻譯**——選擇麥克風或系統音訊,選擇目标,開始。
    一個浮動的疊加視窗即時顯示字幕。
