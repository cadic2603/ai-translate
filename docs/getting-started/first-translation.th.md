# การแปลครั้งแรกของคุณ

การรันแบบ end-to-end ที่รวดเร็ว — น้อยกว่า 5 นาทีเมื่อตั้งค่าเสร็จแล้ว

!!! abstract "ก่อนเริ่มต้น"
    คุณต้องทำ[การติดตั้ง](installation.md)เสร็จและกำหนดค่า LLM API
    key แล้ว Google Gemini tier ฟรีเพียงพอสำหรับการลองครั้งแรก

## แปลเอกสาร Word

1. เปิดแอปเดสก์ท็อป:

    ```bash
    uv run python -m src.main
    ```

2. คลิก **แปลเอกสาร** ในแถบด้านซ้าย

3. ลากไฟล์ `.docx` ใดๆ ไปยังพื้นที่ drop — หรือคลิก **เรียกดู**
   เพื่อเลือก

4. ไฟล์ปรากฏในคิว เลือกภาษาเป้าหมายที่ด้านบน:

    - ต้นทาง: `Auto-detect` (ค่าเริ่มต้น — ถูกต้องโดยทั่วไป)
    - เป้าหมาย: เช่น `French`, `Vietnamese`, `Japanese`,
      `Chinese (Simplified)`

5. คลิก **แปล** (หรือกด `Ctrl+Enter`)

6. ดูแถบความคืบหน้าในตารางประวัติที่ด้านล่างของหน้า เมื่อไปถึง 100%
   คลิก **เปิด** บนแถวเพื่อเปิดไฟล์ที่แปล — บันทึกข้างต้นฉบับด้วย
   suffix `_translated_<src>_<tgt>`

## เกิดอะไรขึ้น

- ไฟล์ `.docx` ของคุณถูกโคลนลงในโฟลเดอร์เก็บข้อมูลสำหรับแต่ละงาน
  เพื่อไม่ให้ต้นฉบับถูกแตะต้อง
- ข้อความถูกแยกออกมา จัดเป็นชุดที่เป็นมิตรกับ LLM แปล แล้วฉีดกลับ
  เข้าไปในเอกสารโดยรักษาการจัดรูปแบบทั้งหมด (ตัวหนา, ตัวเอียง, ฟอนต์,
  สี, headers, footnotes, hyperlinks…)
- มีการเขียนรายการประวัติลงในฐานข้อมูล SQLite เพื่อให้คุณสามารถเปิด
  รัน หรือแปลไฟล์ใหม่ในภายหลังได้

## ลองชัยชนะที่รวดเร็วต่อไป

=== "แปลข้อความธรรมดา"

    ไปที่ **แปลข้อความ** ในแถบด้านข้าง วางอะไรก็ได้ เลือกเป้าหมาย
    กด Enter เอาต์พุตแบบสตรีมมิ่ง, สลับภาษา (`Ctrl+L`), โหมดแก้ไข,
    เล่น TTS

=== "สร้างคำบรรยาย"

    **สร้างคำบรรยาย** — drop ไฟล์ `.mp4` คุณจะได้ `.srt` กลับมาใน
    ภาษาต้นทาง (สำหรับการแปล _และ_ พากย์วิดีโอ ให้ใช้หน้าพากย์เสียง
    แทน)

=== "แปลไมโครโฟนสด"

    **แปลสด** — เลือกไมโครโฟนหรือเสียงระบบ เลือกเป้าหมาย เริ่ม
    หน้าต่าง overlay ลอยจะแสดงคำบรรยายแบบเรียลไทม์
