# ElevenLabs (TTS)

Премиум нейронная синтез речи. Используется страницами
**[Сгенерировать голос](../features/generate-voice.md)**,
**[Дубляж](../features/dubbing.md)** и
**[Живой перевод](../features/live-translation.md)**, когда ты
выбираешь ElevenLabs как метод TTS.

## Получить API-ключ

1. Зарегистрируйся на <https://elevenlabs.io>
2. Открой <https://elevenlabs.io/app/settings/api-keys>
3. Кликни **+ Create New Key**, назови (например "ai-translate"),
   скопируй ключ (выглядит как `sk_...`)

Бесплатный уровень даёт ~10 000 символов / месяц, достаточно для
теста. Продакшен использование начинается примерно с $5/месяц.

## Настройка в приложении

В **Настройки → Сервис**:

1. Вставь ключ в **API-ключ ElevenLabs** → **Сохранить**
2. Введи свой предпочитаемый **ID голоса** в **ID голоса** (найди ID
   на <https://elevenlabs.io/app/voice-lab>; скопируй ID из URL
   голоса). Оставь пустым, чтобы ElevenLabs выбрал по умолчанию.

В **Настройки → Голос**:

1. Установи **Метод TTS** в **ElevenLabs**
2. Выбери **Модель ElevenLabs**:

    | Модель | Лучше всего для |
    |---|---|
    | `eleven_multilingual_v2` (по умолч.) | Общее использование, сбалансированная задержка/качество |
    | `eleven_v3` | Наивысшее качество (использовать для продакшен дубляжей) |
    | `eleven_flash_v2_5` | Наименьшая задержка (использовать для живого перевода) |

## Что он обеспечивает

| Страница | Используй ElevenLabs, когда |
|---|---|
| **Сгенерировать голос** | Ты хочешь озвучки премиум-качества из файлов субтитров |
| **Дубляж** | Ты хочешь высококачественную дорожку дубляжа на переведённом видео |
| **Живой перевод** | Ты хочешь голосовое воспроизведение переведённых субтитров в реальном времени |

## Клонирование голоса

ElevenLabs поддерживает клонирование пользовательских голосов
(платный план). После того как ты склонировал голос на сайте
ElevenLabs, вставь его ID голоса в **Настройки → Сервис → ID голоса**,
и конвейер дубляжа / генерации голоса будет его использовать.

## Оговорки

!!! warning "Pre-flight проверка"
    Страницы Голос / Дубляж проверяют, что твой API-ключ ElevenLabs
    установлен, *перед* началом работы. Если он отсутствует, ты
    получишь дружелюбный диалог, направляющий тебя в Настройки, а не
    наполовину выполненную задачу.

!!! tip "Live-режим автоматически откатывается"
    На странице **Живой перевод**, если ты выбрал ElevenLabs, но не
    настроил ключ, приложение откатывается на **Edge TTS** (бесплатно)
    и сообщает об откате в метке статуса, чтобы ты мог исправить это,
    когда удобно.

!!! info "FFmpeg всё ещё требуется"
    ElevenLabs возвращает аудио-байты; приложение всё ещё использует
    FFmpeg для конвертации между форматами и объединения клипов с
    таймингом в один файл. См. [Настройка FFmpeg](ffmpeg.md).

## Распространённые ошибки

| Ошибка | Вероятная причина |
|---|---|
| `AUTH_ERROR` | Неверный / истёкший API-ключ. Вставь заново в Настройки → Сервис. |
| `QUOTA_ERROR` | Лимит символов бесплатного уровня достигнут или платный план исчерпан. |
| `MODEL_NOT_FOUND` | Выбранная модель ElevenLabs больше недоступна; выбери другую в Настройки → Голос. |
