# Soniox (STT)

Распознавание речи в реальном времени через WebSocket API Soniox.
Используется страницами **[Субтитры](../features/generate-subtitle.md)** и
**[Живой перевод](../features/live-translation.md)**, когда ты
выбираешь Soniox как метод STT.

## Зачем Soniox

- **Реальное время** — токены приходят, пока говорящий ещё говорит.
- **Диаризация говорящих** — метки говорящего на токен
  (например _Говорящий 1: Привет…_).
- **Перевод на лету** — Soniox может переводить во время
  транскрипции, экономя дополнительный LLM-обмен.
- **Многоязычный** — автоопределяет исходный язык даже посреди потока.

## Получить API-ключ

1. Зарегистрируйся на <https://console.soniox.com>
2. Открой **API keys** → **Create new API key**
3. Скопируй его (выглядит как `Bearer ...`; копируй только токен без
   префикса `Bearer `).

Цена считается за минуту аудио (~$0.005 / минуту на момент написания)
— см. <https://soniox.com/pricing>.

## Настройка в приложении

В **Настройки → Сервис**:

1. Вставь ключ в **API-ключ Soniox** → **Сохранить**

В **Настройки → Live** *(для живого перевода)* или
**Настройки → Субтитры** *(для генерации субтитров)*:

1. Установи **Метод STT** в **Soniox**

## Что он обеспечивает

| Страница | Используй Soniox, когда |
|---|---|
| **Субтитры** | Записи с несколькими говорящими (интервью, панели, встречи), где ты хочешь метки говорящих в SRT |
| **Живой перевод** | Субтитрование встреч в реальном времени, особенно с несколькими говорящими |

## Термины глоссария

WebSocket Soniox принимает глоссарий терминов для смещения
распознавания. Приложение автоматически передаёт твои активные записи
глоссария — названия брендов / имена собственные / жаргон
распознаются надёжнее.

## Оговорки

!!! warning "Только онлайн"
    Soniox только облачный; если твоё аудио чувствительное
    (медицинское, юридическое), используй вместо него Whisper
    (локальный).

!!! info "Переподключение"
    WebSocket автоматически переподключается при временных сбоях с
    экспоненциальной задержкой. Длинные сессии остаются подключёнными
    через короткие сбои сети.

## Распространённые ошибки

| Ошибка | Вероятная причина |
|---|---|
| `AUTH_ERROR` | Неверный / истёкший API-ключ. Вставь заново в Настройки → Сервис. |
| `QUOTA_ERROR` | Превышен лимит плана. |
| `CONNECTION_ERROR` | Сеть заблокирована / файрвол. Попробуй из другой сети. |
