Material ships ``pt.html`` (European Portuguese by default) and a separate ``pt-BR.html`` for Brazilian Portuguese, but no ``pt-PT.html``. Same shim pattern as ``en-US`` / ``en-UK``: the i18n plugin force-sets ``theme.language`` from the locale code, so without this file the build crashes looking for ``partials/languages/pt-PT.html``.
